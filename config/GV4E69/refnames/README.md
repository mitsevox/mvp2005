# Reference names

Each TSV lists MVP Baseball 2005 (GV4E69) addresses whose code matched a function in one EA
reference build that ships a symbol file or linker map (the builds in
[docs/reference-builds](../../../docs/reference-builds/README.md)), with that build's name for it.
Names only: no code or data from any build is here.

Columns, tab-separated, no header row: MVP address, size, name in the reference build, the
reference build's object path. The object column is filled only where the build ships a linker
map (fifa05, sims2, uefa) and is empty for symbol-only builds. Names are as the source gives
them, so some are mangled and some demangled.
